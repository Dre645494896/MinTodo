# MinTodo UI 设计规范

参考 [Apple Liquid Glass 指南](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) 与 [Glasswork](https://github.com/kubai087/glasswork)。这是 Web 版的视觉设计，不依赖原生材质或第三方运行库。

- **间距**：使用 4、8、12、16、24 CSS px。4px 用于分段控件内边距，8px 用于标签与字段，12px 用于同一行相邻控件，16px 用于行和字段组之间，24px 用于更大的章节间距。避免用零散的外边距堆出间隔。
- **玻璃层次**：导航和表头共用一块材质；桌面顶部控件组不再单独铺底，只有分段选中块使用玻璃。移动工具栏、浮层采用同一光源方向。玻璃以低色料、适度背景模糊、双侧反光和内缘暗部表达厚度，不逐按钮描边。任务正文、状态和编辑文字保持清晰可读。
- **输入区**：多行编辑区融入面板，不加独立底色、外框或缩放角；保留输入光标，高对比度下保留焦点轮廓。
- **分段切换**：一枚共享选中块滑到所选项，过渡约 340ms；减少动态效果时直接定位，不延迟操作响应。单次操作按钮仍保持原有行为。
- **验收**：窄屏首屏不横向溢出，工具栏与星期列始终对齐，键盘可辨认焦点，手机主要目标至少 44×44 CSS px。视觉迭代先在本地 Demo 验收。
